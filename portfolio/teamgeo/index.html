Командная игра / web

TeamGeo

Версия географической игры для команд

Участники добавляют на карту значимые для себя места, а затем вместе по очереди угадывают их по подсказкам.

Задача

Собрать лёгкий командный сценарий, который помогает знакомиться и обсуждать личные истории через места на карте.

Что сделал

Собрал игровой цикл, состояния раундов, подсчёт очков и адаптивный интерфейс для совместной игры в браузере.
