TeamGeo

A geography game adapted for teams

Participants add meaningful places to a map, then take turns guessing them together from clues.

Goal

Create a light team activity that helps people get to know each other and discuss personal stories through places on a map.

What I did

I built the game loop, round states, scoring, and responsive interface for shared browser play.
