Dia-Log

A quick diary and dose-calculation support for type 1 diabetes

A mobile PWA for meal logging, history, corrections, and dose calculation based on personal context.

Context

This everyday scenario needs few actions, understandable calculations, and constant user control over sensitive data.

What I did

I independently designed the product, UX, data model, API integrations, PWA behaviour, and deployment. I accounted for offline access, cross-device synchronisation, and transparent calculation explanations.

Outcome

Early testing showed a 10-15 percentage-point increase in time in range; meal logging became 4x faster.
